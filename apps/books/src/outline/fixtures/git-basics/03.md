## Git概要

### Gitとは

**Git（ギット）は、プログラムコードを管理するときに便利な分散型管理システムとよばれるものです。**

 ![Git](/api/attachments.redirect?id=cdcd6048-dc24-4302-a8f2-1c046793c09c "source=diagrams.net")

Gitを使うことにより、プログラムコードの編集履歴や古いバージョンのデータを管理できます。

Gitは分散型管理システムと呼ばれている通り、修正前のデータと修正後のデータは別々に保存されているので、修正前のバージョンに戻るのも簡単なのです。

また修正履歴が残るという面から、チームでの開発作業にも適しています。


:::note Gitの開発者は？
Gitは、Linuxカーネルの開発者であるLinus Torvalds氏によって開発されました。

:::


:::note Gitはリモートワークでも大活躍
コロナ禍でリモートワークが増えたこともあり、Gitを使う機会が増えています。Gitを使うことで、複数人での開発作業を効率化することができます。

:::

### Gitが生まれた背景

Gitが生まれた理由を紹介します。Gitは**ファイルの編集やチーム作業などを効率化し分かりやすくするために開発されたシステム**です。

通常ファイルに修正を加える前の状態に戻したい場合、事前にファイルのコピーを取るなどしなければ修正前に戻すことはできません。

また膨大な数のデータをコピーするのは大変ですし、コピーのし忘れや誤操作などのリスクも大きくなります。

さらにチームで共有しているファイルの場合誰がいつ修正したがわからなくなったり、変更内容が消えてしまったりすることも多いです。

このような悩みを解決するために生まれたのがGitなのです。

### Gitでできること

ここからはGitで実際にできることを確認していきましょう。Gitを使ってできることといえば次が挙げられます。

* 編集前ファイルを残したまま編集できる
* バージョンを元に戻す作業が効率化できる
* 修正した箇所をプロジェクトメンバーで共有しやすい
* チームで同じファイルを同時進行で編集出来る
* エクセル、ワード、画像ファイルなどさまざまなファイルが管理できる

#### 編集前ファイルを残したまま編集できる

ひとつ目は編集前のファイルを残したまま編集できるところです。ファイルやコードを編集する際一度元に戻してやり直したい時があると思います。Gitであれば変更前のデータも管理しているので自分が希望する時点までファイルを戻すことが可能です。また修正時点の日付なども記録されているので、修正前に戻すのも簡単です。

 ![](/api/attachments.redirect?id=be239cd6-444b-4edd-a46d-b258f0ae3acb "source=diagrams.net")

#### バージョンを元に戻す作業が効率化できる

2つ目はバージョンを元に戻す作業が効率化できるところです。例えば、WindowsやMacなどのOSでも言えることですが、一度バージョンアップすると、前のバージョンに戻すのは大変ですよね。バージョンを元に戻すことはできますがダウングレードするには一般的にアップグレードの半分程度の時間がかかります。また万が一ダウングレードが失敗する場合に備えてデータのバックアップなども必要なので余分な手間が掛かるのです。その点Gitならファイルのアップデートをしたとしてもアップデート前のファイルもしっかり残っているので簡単に戻せます。

 ![](/api/attachments.redirect?id=8336582d-fb9b-42bd-8bba-25558bb9df36 "source=diagrams.net")

#### 修正した箇所をプロジェクトメンバーで共有しやすい

3つ目は修正した箇所をプロジェクトメンバーで共有しやすいところです。システム開発の現場では各々が担当した箇所のコードを作成編集しますが変更した箇所はチームメンバーで共有する必要があります。チームで共有しておかないとその後の作業で食い違いが生まれるのでしっかりと共有することが大事です。その点Gitならファイルの変更履歴から共有できるので修正点がわからないといったトラブルを防ぎます。

 ![](/api/attachments.redirect?id=cd48571c-553c-4fa3-a23d-d31046c3728a "source=diagrams.net")

#### チームで同じファイルを同時進行で編集出来る

4つ目はチームで同じファイルを同時進行で編集することができるところです。チームでシステム開発をする場合同じファイルを同時に編集するのは難しいです。実際に同じファイルを編集してしまい先に編集していた方の変更内容が消えてしまうトラブルが起こることもあります。Gitを使用すれば同じファイルを同時に編集したとしても両者の変更履歴を反映してくれるのでスムーズにチーム作業を進めることができるのです。このGit機能はチームで作業をすることが多いエンジニアの現場では重宝される機能と言えますね。

 ![](/api/attachments.redirect?id=ecbe25ee-b2a1-4bef-a0c6-472af746d70a "source=diagrams.net")

#### エクセル、ワード、画像ファイルなどさまざまなファイルが管理できる

5つ目はエクセルワード画像ファイルプログラムコードなどさまざまなファイルが管理できるところです。エンジニアにとってはプログラムコードを管理するのに便利なツールですが一般の企業でも、業務書類やプレゼンテーション資料などを保存共有するのにも役立ちます。Gitはプログラムコードだけでなくさまざまなファイルを管理できるので、エンジニア以外の方でも利用することができます。

## リポジトリ

### リポジトリとは

Gitがバージョン管理下に置く場所（フォルダ・ディレクトリ）を「**リポジトリ**」呼びます。そのリポジトリには「ローカルリポジトリ」と「リモートリポジトリ」の2種類があります。（詳細は後述）

 ![](/api/attachments.redirect?id=ebe0db42-6d59-4568-8c6a-de45d397bb53 "source=diagrams.net")

ユーザがそのリポジトリに対して変更の履歴を記録する作業を「**コミット**」と呼びます。コミットは時系列のつながりをもっており、徐々に記録されます。

 ![](/api/attachments.redirect?id=5c768cef-6838-4293-84e4-6b69e94d4ae3 "source=diagrams.net")

また過去のコミットに遡る事もできます。Gitを利用した作業は基本的に「修正→コミット」の繰り返しです。

 ![Gitによる作業の流れ](/api/attachments.redirect?id=35fbfbef-6af5-4aef-a72e-b60211469a08)

### ローカルリポジトリとリモートリポジトリ

自分ひとりだけで開発・制作する場合にはリポジトリは自分のPCにのみあればいいでしょう。

しかし、リポジトリをサーバーに用意してインターネットを介してどこからでも利用したい、あるいたチームでひとつのリポジトリを利用して開発したい、というようなときもあるでしょう。

この場合はサーバー上にリポジトリを置く事になります。そのようなリポジトリを「**リモートリポジトリ**」といいます。また自分のPCに置くだけで完結するリポジトリを「**ローカルリポジトリ**」といいます。

 ![ローカルリポジトリとリモートリポジトリ](/api/attachments.redirect?id=562a7869-9bc4-4004-a5ad-e73b7f114217)

### リモートリポジトリのサービス

リモートリポジトリを提供しているWebサービスとして次のようなものがあります。

* GitHub
* Bitbucket
* GitLab

#### GitHub

GitHubはGitを利用して、世界中の人々が自分のプログラムを保存、公開することができるようにしたWebサービスです。元々はGitHub社にて開発・運用されていましたが2018年にMicrosoft社に買収されました。

 ![GitHub](/api/attachments.redirect?id=4697fe5d-b0c1-432f-b9f9-6853f945704f)

#### GitLab

GitLabは、Gitリポジトリマネージャーであり、Gitリポジトリのホスティング、コードレビュー、問題追跡、CI/CDパイプラインなどの機能を提供するWebベースのGitリポジトリマネージャーです。GitLabは、オープンソースのGitリポジトリマネージャーであり、GitLab Inc.によって開発されています。

 ![GitLab](/api/attachments.redirect?id=55036aff-2dc6-4367-b048-a0e0d9a595d9){w=65}

//clearpage

#### Bitbucket

Bitbucketはアトラシアンが運営するMercurialまたはGitリビジョン管理システムを使用するWebベースのバージョン管理リポジトリホスティングサービスです。

 ![Bitbucket](/api/attachments.redirect?id=8fa01365-400b-46c1-8ff3-7d14df19feae)

//clearpage

### Gitのクライアントツール

Gitそのものは**ターミナル（コンソール）上でコマンドを打ち込んで操作するコマンドラインベースのシステム**です。コマンド操作になれていない人向けにGitをGUIで操作できるようにしたクライアントソフトが多く開発されています。

#### SourceTree

SourceTreeはGitをわかりやすく操作できるように開発されたGUIクライアントソフトです。SourceTreeはWindowsとMacの両対応で日本語にも対応しており、さらに無料で利用する事ができます。 これまでエンジニアにしか使われなかったGitがWebデザイナーやディレクター、Web担当者までに使われるようになったきっかけを作ったソフトウェアともいえます。

 ![Sourcetree](/api/attachments.redirect?id=cdaeb9da-ac4e-4fc5-9287-f2d28c68f174)

#### Visual Studio Code

Visual Studio Code（VSCode）は、Microsoftが開発したオープンソースのコードエディタです。VSCodeはGitをGUIで操作できるようになっており、Gitの操作が苦手な人でも簡単にGitを使うことができます。また拡張機能を追加することでよりソースコード管理を高機能にすることができます。

 ![Visual Studio Code](/api/attachments.redirect?id=cd31a6cb-30a6-4af7-b099-84403b71ed6f){w=85}
