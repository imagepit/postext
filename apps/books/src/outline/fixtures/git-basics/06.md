## Markdown概要

### Markdownとは

Markdown（マークダウン）というのはプログラマーが文章を書くときによく使われるファイル形式です。Markdownを使うと簡単にMicrosoft Wordみたいな文章が書けます。Microsoft Wordみたいな文章ってどういうものかというと、見出しをつけたり、リストを作ったり、リンクを貼ったり、画像を貼ったり、コードを書いたり、テーブルを作ったり、といったことができる文章です。Markdownはそういった文章を簡単に書くためのファイル形式です。

### Markdownを使うメリット

Microsoft Wordはライセンスが必要でもっていない人は使えなかったり、文章を書くためだけにワードを開かないといけない、などがあります。

#### ライセンスが不要でテキストエディターで書ける

Markdownの場合は、ライセンスが必要ないし、テキストエディターで書けるので、ワードを開かなくてもいいです。また、Markdownはシンプルなファイル形式なので、テキストエディターで書いても、Wordのように見栄えが悪いということがありません。

 ![](/api/attachments.redirect?id=4a87ecc1-1714-4def-a4c4-3f3d0a9335be)

#### MarkdownはHTMLに変換できる

また、MarkdownはHTMLに変換することができるので、Webページを作ることもできます。次のGitHubのリポジトリページは、Markdownで記述されて`README.md`というファイルがHTMLに変換されて表示されています。

 ![](/api/attachments.redirect?id=0edb8a6c-a17c-4933-bad1-268272adcdd9)


:::note MarkdownはVSCodeで書くと便利
MarkdownはVSCodeで書くと便利です。VSCodeはMarkdownのプレビュー機能がついているので、書いているときにどういう風に表示されるかを確認できます。また、VSCodeはMarkdownのシンタックスハイライト機能がついているので、書いているときにどこが見出しでどこがリストなのかがわかりやすいです。

:::

## Markdownファイルを作成する

Markdownファイルを作成してみましょう。Markdownファイルを作成するときは、VSCodeを使って作成します。VSCodeはMarkdownのプレビュー機能がついているので、書いているときにどういう風に表示されるかを確認できます。また、VSCodeはMarkdownのシンタックスハイライト機能がついているので、書いているときにどこが見出しでどこがリストなのかがわかりやすいです。

### プロジェクトフォルダの作成

まずは、プロジェクトフォルダを作成します。プロジェクトフォルダは、Markdownファイルを保存するためのフォルダです。プロジェクトフォルダを作成するときは、適当な名前をつけて、デスクトップなどの場所に作成してください。

:::step
1. VSCodeで作業フォルダを開く

   デスクトップにある`work`フォルダをVSCodeで開きます。

   ![](/api/attachments.redirect?id=0ec4428f-c47c-485b-8d1e-dd80dabc798b)
2. Markdown練習用のフォルダを作成

   VSCodeのエクスプローラーでフォルダのアイコンをクリックして新しいフォルダー作成します。フォルダ名を`markdown`にします。

   ![](/api/attachments.redirect?id=3127dd7b-2bf2-4ce6-8fca-0f47b0492508)
3. Markdownファイルを作成

   エクスプローラーで`markdown`フォルダの中に`sample.md`というファイルを作成します。

   ![](/api/attachments.redirect?id=8d2260f4-be3f-4098-8ce4-c0ab64e45263)
4. 見出しを書く

   `sample.md`を開いて、以下の見出しを書いて保存します。

   *work/markdown/sample.md*

   ```markdown
   //addstart
   # Markdownの練習
   //addend
   ```

   ![](/api/attachments.redirect?id=dde32be6-2940-4b05-9d9d-c66228781608)
5. プレビューを表示

   VSCodeの右側に表示しているプレビューのアイコンをクリックします。

   ![](/api/attachments.redirect?id=66665110-dab4-455b-96d2-d22409d34e28)

   次のようにプレビュー画面に見出しが表示されていることを確認します。

   ![](/api/attachments.redirect?id=38f896cf-4a17-4531-a37b-38343bb3932a)

:::

このように、Markdownファイルを作成することで、簡単に見出しをつけたり、リストを作ったり、リンクを貼ったり、画像を貼ったり、コードを書いたり、テーブルを作ったり、といったことができます。Markdownファイルを作成するときは、VSCodeを使って作成すると便利です。次から、Markdownの基本構文を学んでいきましょう。

## Markdownの基本構文

### 見出し

見出しは`#`を使って書きます。`#`の数が多いほど小さな見出しになります。それでは実際に見出しを書いてみましょう。

:::step
1. 見出しを書く

   `sample.md`に以下を追記して保存します。

   *work/markdown/sample.md*

   ```markdown
   # Markdownの練習
   //addstart
   ## 見出し2
   ### 見出し3
   #### 見出し4
   ##### 見出し5
   ###### 見出し6
   //addend
   ```
2. プレビューを表示

   プレビューを表示します。次のように、見出しが表示されていることを確認します。`#`の数が多いほど小さな見出しになります。

   ![](/api/attachments.redirect?id=5daccb81-b02b-42b5-bea2-19c6a298b81b)

:::

### リスト

リストは`-`を使って書きます。リストの中にリストを入れることもできます。それでは実際にリストを書いてみましょう。


:::syntax リスト
```
- リスト
```

:::

:::step
1. Markdownファイルの編集

   `sample.md`を開いて、以下のリストを書いて保存します。

   *work/markdown/sample.md*

   ```markdown
   # Markdownの練習
   ## 見出し2
   ### 見出し3
   #### 見出し4
   ##### 見出し5
   ###### 見出し6
   
   //addstart
   ## リスト
   
   - リスト1
   - リスト2
     - リスト2-1
     - リスト2-2
   - リスト3
   //addend
   ```
2. プレビューを表示

   プレビューを表示します。次のように、リストが表示されていることを確認します。

   ![](/api/attachments.redirect?id=46a5af8d-7c69-4974-b60c-1a5f40152071)

:::

### リンク

リンクは`[リンク名](URL)`を使って書きます。リンク名をクリックすると、URLに飛ぶようになります。それでは実際にリンクを書いてみましょう。


:::syntax リンク
```
[リンク名](URL)
```

:::

:::step
1. Markdownファイルの編集

   `sample.md`を開いて、以下のリンクを書いて保存します。

   *work/markdown/sample.md*

   ```markdown
   # Markdownの練習
   :
   （省略）
   :
   //addstart
   ## リンク
   
   [Google](https://www.google.com/)は、世界最大の検索エンジンです。
   //addend
   ```
2. プレビューを表示

   プレビューを表示します。次のように、リンクが表示されていることを確認します。

   ![](/api/attachments.redirect?id=1b96bd4b-0eca-4956-bd9f-efd937d41653)

:::

### 画像

画像は<code>!\[代替テキスト](画像のURL)</code>を使って書きます。代替テキストは画像が表示されないときに代わりに表示されるテキストです。それでは実際に画像を書いてみましょう。

`代替テキスト`と`画像のURL`を、それぞれ表示したい説明と画像の場所に置き換えます。

:::step
1. 画像のダウンロード

   Googleで画像検索して任意の画像をダウンロードします。

   ![](/api/attachments.redirect?id=f0a23f48-3d60-4717-90c5-324252c652ff)
2. 画像をプロジェクトフォルダに保存

   ダウンロードした画像を`work/markdown`フォルダに保存します。画像名は`sample.画像の拡張子`とします。

   ![](/api/attachments.redirect?id=7d94b267-8cfe-472f-b04e-8006f3864274)
3. Markdownファイルの編集

   `sample.md`を開いて、以下の画像を書いて保存します。

   *work/markdown/sample.md*

   ```markdown
   # Markdownの練習
   :
   （省略）
   :
   //addstart
   ## 画像
   
   ![画像の説明](sample.png)
   //addend
   ```
4. プレビューを表示

   プレビューを表示します。次のように、画像が表示されていることを確認します。

   ![](/api/attachments.redirect?id=3778c09d-744b-4474-961f-715c96f64d76)

:::

### コード（インライン）

文章の中にインラインでコードを入れる場合は、バッククォート「\`」を使って書きます。バッククォートを使うと、コードの中身がそのまま表示されます。それでは実際にコードを書いてみましょう。

:::syntax コード（インライン）
```
`コード`
```

:::

:::step
1. Markdownファイルの編集

   `sample.md`を開いて、以下のコードを書いて保存します。

   *work/markdown/sample.md*

   ```markdown
   # Markdownの練習
   :
   （省略）
   :
   //addstart
   ## コード
   
   PythonのHello Worldを表示するコードは`print('Hello, World!')`です。
   //addend
   ```
2. プレビューを表示

   プレビューを表示します。次のように、コードが表示されていることを確認します。

   ![](/api/attachments.redirect?id=9a2e46d9-2145-4aef-bb05-b5b97f2c1413)

:::

### コードブロック

コードブロックはバッククォート3つ「```` ``` ````」を使って書きます。バッククォート3つを使うと、コードの中身がそのまま表示されます。それでは実際にコードブロックを書いてみましょう。


:::syntax コードブロック
````
​```言語（例：java、html、css、pyなど）
コード
​```
````

:::

:::step
1. Markdownファイルの編集

   `sample.md`を開いて、以下のコードブロックを書いて保存します。

   *work/markdown/sample.md*

   ````markdown

   :
   （省略）
   :
   //addstart
   ## コードブロック
   
   ```java
   public class HelloWorld {
     public static void main(String[] args) {
       System.out.println("Hello, World!");
     }
   }
   ```
   //addend
   ````
2. プレビューを表示

   プレビューを表示します。次のように、コードブロックが表示されていることを確認します。

   ![](/api/attachments.redirect?id=5ca42f56-1060-4910-aa7f-c421996e8336)

:::

### テーブル

テーブルは`|`と`-`を使って書きます。`|`で区切って列を作り、`-`を使って区切ることでヘッダーとボディを分けます。それでは実際にテーブルを書いてみましょう。


:::syntax テーブル
```
表見出し1 | 表見出し2 | 表見出し3
--- | --- | ---
表1-1 | 表1-2 | 表1-3
表2-1 | 表2-2 | 表2-3
表3-1 | 表3-2 | 表3-3
```

:::

:::step
1. Markdownファイルの編集

   `sample.md`を開いて、以下のテーブルを書いて保存します。

   *work/markdown/sample.md*

   ```markdown
   # Markdownの練習
   :
   （省略）
   :
   //addstart
   ## テーブル
   
   商品名|単価|個数
   ---|---|---
   りんご | 100 | 3
   バナナ | 50 | 2
   みかん | 80 | 5
   //addend
   ```
2. プレビューを表示

   プレビューを表示します。次のように、テーブルが表示されていることを確認します。

:::

## Markdownファイルの活用

Markdownファイルは、作成した後にHTMLやPDFに変換できます。HTMLに変換することで、Webページを作ることができたり、PDFファイルにして配布できます。それでは、MarkdownファイルをHTMLに変換してみましょう。

### MarkdownファイルをHTMLに変換

MarkdownファイルをHTMLに変換するには、MarkdownファイルをHTMLに変換するツールを使います。今回はVSCodeの拡張機能「Markdown All in One」を使ってMarkdownファイルをHTMLに変換します。

:::step
1. MarkdownファイルをHTMLに変換

   `sample.md`を開いて、プレビューの場所で、右クリックして「`Export`->`HTML`->`HTML(offline)`」を選択します。`sample.html`というHTMLファイルが作成されます。

   ![](/api/attachments.redirect?id=3d610147-01aa-4664-9dbe-a13decb361db)
2. HTMLファイルを開く

   `sample.html`を右クリックして「`Open in Default Browser`」を選択します。

   ![](/api/attachments.redirect?id=cad8f7c6-0830-4a97-ab90-5add310b1648)

   ブラウザが開いて、HTMLファイルが表示されていることを確認します。

   ![](/api/attachments.redirect?id=ffb77ddf-2a9e-4bc1-b2d4-9af2d6aac41a)

:::

このように、MarkdownファイルをHTMLに変換することで、Webページを作ることができます。

### MarkdownファイルをPDFに変換

MarkdownファイルをPDFに変換するには、VSCodeの拡張機能「Markdown PDF」を使います。MarkdownファイルをPDFに変換する方法は、以下の手順で行います。

:::step
1. MarkdownファイルをPDFに変換

   `Ctrl + Shift + P`を押して、コマンドパレットを開きます。次に、`Markdown PDF: Export (pdf)`を選択します。

   ![](/api/attachments.redirect?id=232f7741-04ea-49ea-8990-871caa0a0443)

   `sample.pdf`というPDFファイルが作成されます。

   ![](/api/attachments.redirect?id=2ac106fa-4b54-4260-a920-d32d4cc0da10)
2. PDFファイルを開く

   `sample.pdf`を開いて、PDFファイルが正しく表示されていることを確認します。

   ![](/api/attachments.redirect?id=b664cba2-c2e1-43f0-a1ef-cb73b6cbc26b)

:::

このように、MarkdownファイルをPDFに変換することで、配布用の資料を作ることができます。

MarkdownファイルをHTMLやPDFに変換することで、簡単にWebページや資料を作成できます。
